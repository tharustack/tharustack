## 👋 About me

I'm **Tharusha Dilshan** (Tharu), a freelance developer from Sri Lanka. I run **[Triven](https://trivenlab.space)**, a small product studio where I build and ship my own products, and I take on client projects from time to time.

- 🇱🇰 I like building things made for Sri Lankan users
